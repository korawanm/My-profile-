สิ่งที่ฉันได้เรียนรู้
index.html คืออะไร?
คือ "หน้าแรก" ของเว็บไซต์ เป็นไฟล์ที่เบราว์เซอร์เปิดขึ้นมาก่อนเมื่อเรา Double Click เข้าไปที่โฟลเดอร์ เปรียบเหมือนหน้าปกบ้านที่บอกว่าเราเป็นใคร

about.html คืออะไร?
คือ "หน้าที่สอง" ของเว็บไซต์ ใช้แสดงข้อมูลละเอียดเพิ่มเติม เช่น งานอดิเรก สิ่งที่ชอบ เปรียบเหมือนห้องข้างในที่แขกเดินเข้ามาดูต่อจากหน้าปก

style.css คืออะไร?
คือไฟล์ที่รวม "คำสั่งตกแต่ง" ทั้งหมดไว้ที่เดียว เช่น สี พื้นหลัง ฟอนต์ ขนาดตัวอักษร ความโค้งมน ทั้งสองหน้าใช้ไฟล์ร่วมกัน จึงทำให้ทั้งเว็บดูโทนเดียวกัน และเวลาอยากเปลี่ยนสีก็แก้แค่ที่เดียว

<a href="about.html"> ทำหน้าที่อะไร?
คือ "ป้ายบอกทาง" ที่บอกเบราว์เซอร์ว่า เมื่อผู้ใช้งานกดคลิก ให้เปิดไฟล์ชื่อ about.html ขึ้นมาแสดง ส่วน href คือที่อยู่ของไฟล์ปลายทางนั่นเอง

เราเชื่อมหน้าเว็บหลายหน้าเข้าด้วยกันได้อย่างไร?
ใช้แท็ก <a href="ชื่อไฟล์"> วางลิงก์ข้ามไปมา เช่น หน้าแรกมีลิงก์ไป about.html และหน้า about มีลิงก์กลับ index.html เพียงเท่านี้ก็กดสลับหน้าไปมาได้โดยไม่ต้องใช้ JavaScript เลย ขอแค่ไฟล์อยู่ในโฟลเดอร์เดียวกันก็ใช้ได้ทันที

HTML กับ CSS ทำงานร่วมกันอย่างไร?
HTML เป็นคน "สร้างโครงและเนื้อหา" เช่น ข้อความ รูป ปุ่ม รายการ ส่วน CSS เป็นคน "ตกแต่งความสวยงาม" เช่น ทาสี จัดกึ่งกลาง ทำมุมมน เพิ่มเงา โดยทั้งสองไฟล์เชื่อมกันผ่านคำสั่ง <link rel="stylesheet" href="style.css"> ในหัวของทุกหน้า HTML — เหมือนมีโครงบ้าน (HTML) แล้วค่อยทาสีแต่งบ้าน (CSS) ให้สวยงามนั่นเอง 🏠
